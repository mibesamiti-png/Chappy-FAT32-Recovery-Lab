## New bounded A integration mode

`Invoke-ChappyA7FragmentPhysicalReceipts -EnableA7FragmentReceipts -EnableStandardFAT32DataWindow` in `core/Chappy.FragmentPhysicalReceipts.psm1`:

- Without `EnableA7FragmentReceipts`, disabled and no reads. Existing compact 2MiB default branch remains unchanged; a standards-sized image without new explicit opt-in is rejected without source reads.
- With both switches, permit only `IO.MemoryStream`, nonwritable, seekable/readable synthetic source between 64KiB and 100MiB. A wraps it in its single protected `ChappyA7LiveMeterV1` in-process Stream; all actual successful return bytes and source-local unique byte positions are measured by A.
- Under A meter consumer `geometry`, call **actual B** `Get-ChappyFat32Geometry` on source bytes. Only accept plausible numeric FAT32 geometry (at least 65,525 clusters, FAT count two, sector-aligned data-region origin above first 64KiB, and physical window within input). This is **B numeric hypothesis, NOT authenticated original volume geometry or exact file start/tail**; field `dataWindowOrigin=A_in_process_B_numeric_geometry_unverified`.
- Set `C Get-ChappyFragmentCandidates` window to the B-derived 32768B physical data-region start; invoke its newly merged default-off C #172 `-EnableStandardsShapedSource`, fixed `IncludeStartPhasePlusTwo` and `IncludeFirstPiece560` finite hypotheses applied equally to EVERY case. Original fragment extents and generated truth SHA are NEVER passed into B, C or A candidate selection. C scout uses `carving` consumer, caps 81,920B source and 98,304B separate in-memory validator, max 128 sector probes, 4 start /8 tail/16 pair hypotheses, original=UNKNOWN.
- Resolve each actual C candidate `candidateKey` and **ordered source-relative** two-piece spans through A `Resolve-ChappyCandidateDefinitionBoundary`. Under **same A meter** consumer `candidate_validation` re-read every proposed physical extent using positive-return `Stream.Read` actual events, verifying expected offset/returned length and candidate-specific bounds; emit `source_observed` only for fully returned *source* bytes. Separately count B geometry, C search, A validation returned B, unique/repeated and actual physical calls. Never elevate a ZIP/CRC-consistent candidate to original identical bytes.
- Real originalIdentity `unknown`, originalShaVerified `false`, canSelectOriginal `false`, canExport `false`, canRepair `false`. Unsupported/conflicting B hypothesis, 17B then zero physical EOF, total A source quota or writable input yield UNKNOWN/no authenticated candidates; no real file path, payload, private name or user device access.
