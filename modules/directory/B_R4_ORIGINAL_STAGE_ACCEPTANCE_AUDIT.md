### Evidence boundary and exact denominators

- **No pooled precision/recall:** The root M00/M01/M04/X02 *file-size-warning* unit (24 per method), LFN association (12), deleted visibility (12), orphan-vs-decoy candidate (24), hidden-parent truth (12), observed source parent graph (12) and standards-sized root candidate *instances* (6) are **different populations and verdict questions**. Abstentions never count as TN or recovered files. Some synthetic controls have identical physical reads but different unseen truth; this is a proof of non-identifiability, not a solved recovery.
- **Explicit coverage:** B R2 root cap is 512 B; B4-02 9,728 B directory/case; parent controls exactly three 512 B clusters when fully returned. In R3 standards-shaped FAT32 each new B test covers **one out of 65,541 data clusters**, not the filesystem. The source may hold valid originals outside the read window; this is **UNKNOWN**. A actual in-process returned meter owns source/phase observations; the B outer comparison alone is marked `consistent_unattested` and cannot authenticate the caller-provided event list.
- **Resources:** B test wraps readonly artificial streams with a 97 B per `Read` maximum, hard caps for physical returns and calls, and checks positive-return source offsets, lengths and SHA. The new standard test independently computes **unique successful source interval union**, which is not necessarily equal to total returned bytes on arbitrary repeated input. Stopwatch measures scanner elapsed time. `PeakWorkingSet64` is a **global cumulative process peak after generating images and running earlier suites**, therefore it is *not* an isolated B scanner high-water measurement or a hard implementation memory bound; no comparative memory speedup is claimed.
- **Safety:** No actual microSD, only master ~31GB IMG, private files/names, original logs, or user data can be read, hashed, scanned, copied, repaired, exported, uploaded or changed. Real-media gate stays **NOT APPROVED**. Artificial fixtures only; the A standard fixture generator and B tests never open a file/device path for source reads. B cannot issue A source receipts or approve future local trials.
- **Licenses:** Microsoft FAT File System Specification v1.03 and .NET `Stream.Read` semantics are references, not copied implementation; mixed-license TSK and Linux FAT GPL code are not reused.
